# INVENTOR O.S. Command Center — índice

Centro local para memoria Markdown, proyectos Git, Prompt Foundry y agentes. Este archivo es el
índice: abrí solamente la rama necesaria.

| Necesitás | Leé |
|---|---|
| Arquitectura, datos y flujos | `docs/ARBOL_CONOCIMIENTO.md` |
| Estado y fases | `PLAN.md` |
| Reglas y definición de terminado | `.agents/skills/inventor-os/SKILL.md` |
| Frontend y grafo | `src/` |
| API local, memoria y Git | `server/core/` y `server/index.mjs` |
| Foundry, Ollama y agentes | `server/features/` y `../../foundry/` |
| Arranque de escritorio | `scripts/desktop/` |

La memoria personal no vive en el repositorio. Se crea bajo `INVENTOR_OS_HOME` o en la carpeta local
de datos de la persona y puede abrirse directamente con Obsidian.
