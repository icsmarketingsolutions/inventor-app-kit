## Memoria viva

Antes de trabajar, leé `memory/INDEX.md`; desde ahí revisá las directivas,
decisiones relevantes y el reporte más reciente. Al cerrar una sesión significativa:

- decisión duradera -> `memory/10-decisions/`;
- conocimiento estable -> `memory/20-knowledge/`;
- acción humana o externa -> `memory/30-directives/directives.md`;
- resumen verificable -> `memory/90-reports/`;
- arquitectura, tablas o flujos -> `docs/ARBOL_CONOCIMIENTO.md`;
- trampa nueva que hizo perder tiempo -> skill del proyecto.

Actualizá `memory/INDEX.md` cuando agregues una decisión, conocimiento o reporte
que deba ser la entrada recomendada para la próxima sesión.

Usá enlaces Markdown relativos. No guardés secretos, datos personales, volcados de
conversación ni información que ya vive claramente en el código.
