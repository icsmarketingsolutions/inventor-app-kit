# Decisión 0001: fundación web con Supabase

La app empieza como Vite + React + TypeScript y usa Supabase para Auth y datos. Puede
mostrar un modo demostración sin credenciales para que la primera experiencia no
dependa de Docker ni de una cuenta remota.

La experiencia principal elegida es **__INVENTOR_PRIMARY_USE_LABEL__**
(`__INVENTOR_PRIMARY_USE__`). Esta preferencia guía la prioridad de navegación,
densidad y controles; la app debe seguir siendo responsive y accesible desde
móvil, tableta y escritorio.

Toda estructura de datos nace como migración y se valida desde cero localmente.
